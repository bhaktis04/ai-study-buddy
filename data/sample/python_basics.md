# Python Basics

## Lists
A list is an ordered, mutable collection written with square brackets, like [1, 2, 3].
You can add items with append(), remove them with remove() or pop(), and slice with my_list[1:3].
Lists can hold mixed types, for example [1, "apple", True].

## Dictionaries
A dictionary stores key-value pairs inside curly braces, like {"name": "Asha", "age": 21}.
Access a value with d["name"]. Use d.get("city") to avoid a KeyError when a key is missing.
Keys must be unique and immutable, such as strings or numbers.

## Decorators
A decorator is a function that wraps another function to add behavior without changing its code.
It is applied with the @ symbol above a function definition.
Common uses are logging, timing, and access control.

## SQL Joins
INNER JOIN returns only rows that match in both tables.
LEFT JOIN returns all rows from the left table and matching rows from the right, with NULL where there is no match.
